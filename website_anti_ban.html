Hosting, domain, CDN, dan backup strategy agar website tidak bisa dimatikan

Kenapa website bisa diblokir dan bagaimana cara bypassnya

3 cara Kominfo memblokir website: DNS blocking (paling umum), IP blocking, dan deep packet inspection (DPI). Masing-masing punya cara bypass yang berbeda. Dengan setup yang benar, semua bisa diatasi.
1
DNS Blocking — cara paling umum, paling mudah dibypass
95% pemblokiran Kominfo menggunakan metode ini
Ketika kamu ketik "namasitus.com", HP kamu tanya ke DNS server ISP (Telkomsel/Indosat/XL): "IP berapa sih namasitus.com?" — ISP yang sudah dapat perintah Kominfo akan jawab "tidak ada" atau kasih IP halaman blokir.

Cara bypass: Paksa semua pengunjung website pakai DNS alternatif (Cloudflare 1.1.1.1 atau Google 8.8.8.8) lewat pengaturan di Cloudflare. Atau lebih efektif lagi: setup DNS-over-HTTPS di website sehingga request DNS dienkripsi dan ISP tidak bisa intercept.
✓ Cloudflare gratis sudah handle ini otomatis — pasang dan selesai
2
IP Blocking — blokir langsung IP server
Lebih jarang, tapi lebih sulit dibypass tanpa Cloudflare
ISP memblokir IP address server langsung, bukan domain-nya. Ini lebih serius karena mengganti domain tidak membantu kalau IP-nya masih sama.

Cara bypass: Cloudflare adalah solusi utama — Cloudflare menyembunyikan IP asli server kamu dan menampilkan IP Cloudflare sebagai gantinya. IP Cloudflare tidak akan diblokir karena dipakai jutaan website besar termasuk layanan pemerintah. Tanpa Cloudflare, harus ganti hosting dan IP baru setiap kali diblokir.
✓ Cloudflare = IP asli server tersembunyi, tidak bisa diblokir langsung
3
Deep Packet Inspection (DPI) — paling jarang, paling sulit
Hanya dipakai untuk website yang sangat diprioritaskan untuk diblokir
DPI menganalisis isi traffic secara langsung meskipun sudah pakai HTTPS. Ini teknologi mahal yang biasanya hanya dipakai untuk situs yang dianggap berbahaya serius oleh pemerintah.

Cara bypass: HTTPS + Cloudflare + domain yang tidak terlihat mencurigakan. Website biasa dengan konten yang tidak terlalu eksplisit di halaman utama (konten di balik login/klik) jarang kena DPI. Jangan pakai keyword eksplisit di nama domain atau meta tag halaman.
⚠ Jarang terjadi untuk website kecil — tidak perlu terlalu khawatir ini

Strategi domain yang sulit diblokir dan diidentifikasi

Prinsip domain anti-ban: Domain tidak boleh terlihat seperti website adult dari namanya saja. Nama yang terlalu eksplisit = langsung diblokir via keyword filter otomatis. Pilih nama yang netral, ambigu, atau terlihat seperti website konten biasa.
Nama netral + TLD aman
Nama yang bisa diartikan banyak hal — tidak ada keyword eksplisit. Gunakan TLD yang tidak langsung diasosiasikan adult.
koleksiindo.store
paketharian.xyz
mediahub.site
TLD yang susah diblokir
.xyz, .store, .site, .online — murah, tidak ada koneksi ke adult content, lebih susah diblokir massal karena banyak dipakai website biasa juga.
namasitus.xyz
namasitus.store
namasitus.online
Beli 3+ domain sekaligus
Kalau domain utama diblokir, langsung ganti ke domain backup. Beri tahu audience domain backup via Twitter/WA sebelum diblokir.
domain1.xyz (utama)
domain2.store (backup 1)
domain3.online (backup 2)

Strategi domain terbaik: Beli 3 domain dengan nama netral dari registrar yang berbeda (misal Porkbun, Namecheap, dan DomaiNesia). Set semua 3 domain ke website yang sama. Kalau domain pertama diblokir, langsung announce domain kedua ke audience kamu di Twitter. Proses ini bisa diulangi terus karena domain murah — Rp 20–50rb per tahun per domain.

Cloudflare — setup gratis yang memberi proteksi enterprise

Cloudflare gratis adalah lapisan perlindungan terpenting. Tanpa Cloudflare, IP server kamu terekspos dan bisa diblokir langsung. Dengan Cloudflare, yang terekspos adalah IP Cloudflare yang dipakai jutaan website — tidak akan diblokir ISP karena akan mematikan ribuan website lain sekaligus.
1
Daftar Cloudflare gratis di cloudflare.com
Buat akun di cloudflare.com → Add a Site → masukkan domain kamu → pilih plan Free. Cloudflare akan scan DNS records domain kamu secara otomatis. Proses daftar 5 menit.
Free plan sudah lebih dari cukup untuk proteksi anti-ban
2
Ganti nameserver domain ke Cloudflare
Cloudflare akan kasih 2 nameserver baru (contoh: anna.ns.cloudflare.com). Login ke registrar domain kamu (Porkbun/Namecheap) → Domain Settings → Nameservers → ganti ke nameserver Cloudflare. Propagasi 5–30 menit. Setelah ini semua traffic ke domain kamu lewat Cloudflare dulu.
Setelah ini IP asli server tersembunyi 100%
3
Aktifkan fitur perlindungan di dashboard Cloudflare
SSL/TLS: Set ke "Full (strict)" — enkripsi end-to-end, lebih susah di-inspect
Under Attack Mode: Aktifkan kalau ada serangan/traffic mencurigakan
Browser Integrity Check: ON — block bot dan scraper
Rocket Loader: ON — website lebih cepat
Always Use HTTPS: ON — redirect semua HTTP ke HTTPS
Semua setting ini ada di Free plan, tidak perlu upgrade
4
Sembunyikan nama server asli (origin server)
Pastikan DNS record utama (A record) punya ikon oranye "proxied" di Cloudflare — ini artinya traffic lewat Cloudflare dan IP asli tersembunyi. Jangan ada record yang "DNS only" (abu-abu) kecuali untuk subdomain yang memang mau kamu ekspos (seperti mail server).

Penting: jangan pernah sebut nama hosting atau IP server di mana pun secara publik — ini yang paling sering jadi celah exposure IP asli.
Ikon oranye = IP tersembunyi. Abu-abu = IP terekspos
5
Setup Cloudflare Page Rules untuk konten sensitif
Di Page Rules, tambahkan rule: URL match "*namasitus.xyz/*" → Security Level: High + Cache Level: No Cache untuk halaman yang berisi konten sensitif. Ini mencegah Cloudflare meng-cache konten sensitif di server mereka yang mungkin trigger review.

Untuk halaman utama/landing yang tampak normal, biarkan caching aktif untuk performa lebih baik.
Konten sensitif tidak di-cache Cloudflare = lebih aman dari review otomatis

Sistem backup — agar tidak panik saat satu domain diblokir

Prinsip utama: Website tidak bisa benar-benar "anti-ban" 100% — yang bisa kamu lakukan adalah memastikan waktu downtime sangat singkat (menit, bukan hari) dan audience kamu selalu tahu ke mana harus pergi selanjutnya.
📌
Sistem 3 Domain — rotasi otomatis
Wajib punyaSetup sekali
Beli 3 domain sekaligus dengan nama berbeda. Semua 3 domain point ke server yang sama — jadi kalau 1 diblokir, 2 lainnya langsung bisa dipakai tanpa setup ulang apapun.

Umumkan ke audience di Twitter/WA: "Website utama: domain1.xyz | Backup 1: domain2.store | Backup 2: domain3.online". Kalau domain1 diblokir, audience langsung tahu pakai domain2. Kamu tidak perlu umumkan lagi karena mereka sudah tahu dari awal.
✓ Kalau 1 diblokir, 2 lainnya aktif dalam hitungan detik
🔔
Twitter sebagai "anchor" permanen
Paling stabil
Twitter/X adalah platform yang paling kecil kemungkinannya diblokir secara permanen di Indonesia — kalau Twitter diblokir, itu masalah yang jauh lebih besar dari sekedar website kamu. Jadikan akun Twitter sebagai sumber kebenaran utama: selalu announce domain aktif terbaru di bio Twitter.

Audience yang sudah follow Twitter kamu tidak akan pernah kehilangan akses ke kontenmu, apapun yang terjadi dengan domain website.
✓ Twitter = jangkar yang tidak bisa diputus selama Twitter masih jalan
📧
Push notification + email list
Paling powerful jangka panjang
Pasang OneSignal (push notification gratis hingga 30.000 subscriber) di website. Setiap pengunjung yang klik "Allow" notifikasi bisa kamu kirimi update kapanpun — termasuk pemberitahuan "domain lama diblokir, pindah ke sini".

Push notif dikirim langsung ke browser/HP mereka, tidak bergantung pada platform apapun. Ini aset paling berharga yang kamu miliki karena tidak bisa diambil oleh siapapun.
✓ 30.000 subscriber push notif = 30.000 orang bisa kamu hubungi langsung kapanpun

Setup lengkap dari nol — urutan yang benar

Total biaya setup anti-ban: Domain 3x ~Rp 60–150rb/tahun + Hosting Contabo/Hostinger ~Rp 70rb/bulan + Cloudflare gratis + WordPress gratis + OneSignal gratis = ~Rp 70rb/bulan + Rp 150rb sekali untuk domain. Sangat murah untuk infrastruktur yang solid.
1
Beli 3 domain dengan nama netral (hari 1)
Beli dari Porkbun.com (paling murah, ~$9/tahun untuk .com atau $2/tahun untuk .xyz). Beli 3 sekaligus dengan nama yang berbeda tapi serupa: misalnya "koleksiindo.xyz", "paketharian.store", "mediahubid.online". Bayar dengan kartu debit/PayPal.
3 domain = ~$6–27/tahun total, setara Rp 100–440rb
2
Setup hosting Contabo atau Hostinger (hari 1)
Daftar Contabo VPS S (4GB RAM, €4.50/bln) atau Hostinger Premium (1GB, $2.99/bln). Untuk pemula Hostinger lebih mudah — ada cPanel dan instalasi WordPress 1-klik. Contabo lebih powerful tapi butuh sedikit pengetahuan server. Bayar dengan kartu/PayPal.
Hostinger = lebih mudah. Contabo = lebih kuat dan lebih privat
3
Hubungkan semua 3 domain ke Cloudflare (hari 1)
Daftar Cloudflare → tambahkan ketiga domain → ubah nameserver di Porkbun ke nameserver Cloudflare. Set A record semua 3 domain ke IP server hosting yang sama. Aktifkan proxy (ikon oranye) untuk semua. Sekarang ketiga domain mengarah ke website yang sama dan IP asli tersembunyi.
Semua gratis, setup 30 menit
4
Install WordPress + tema sederhana (hari 1–2)
Di cPanel Hostinger: Softaculous → WordPress → Install. Pilih tema ringan seperti Astra atau GeneratePress. Ini template kosong yang akan kamu isi dengan halaman konten dan bicolink. WordPress memudahkan pengelolaan banyak halaman dan plugin yang dibutuhkan.
1-klik install = WordPress aktif dalam 2 menit
5
Pasang plugin wajib (hari 2)
Wordfence Security — proteksi dari brute force dan malware
WP Super Cache — website lebih cepat
OneSignal Push Notification — kumpulkan subscriber push notif
UpdraftPlus — backup otomatis ke Google Drive
WP Content Copy Protection — cegah orang mudah copy konten
Semua gratis, install dari dashboard WordPress
6
Struktur halaman yang aman
Halaman utama (index) harus terlihat normal dan tidak mencurigakan — bisa berupa halaman "download pack" umum atau blog biasa. Konten yang lebih sensitif ada di halaman dalam yang hanya bisa diakses setelah klik beberapa kali.

Ini penting karena bot Kominfo biasanya hanya scan halaman utama untuk deteksi otomatis. Kalau halaman utama bersih, website tidak masuk daftar prioritas blokir.
Halaman utama bersih = tidak masuk radar filter otomatis
7
Announce ke audience — domain utama dan backup
Di bio Twitter, di WA Channel, di semua platform: tulis semua 3 domain kamu. "Main: domain1.xyz | Backup: domain2.store | domain3.online". Kalau domain utama suatu hari diblokir, audience sudah tahu langsung pindah ke backup tanpa harus nanya ke kamu.
Pre-announce backup domain = tidak ada downtime di mata audience
Ringkasan: website yang tidak bisa benar-benar dimatikan

Selama kamu pakai: hosting luar negeri + Cloudflare (sembunyikan IP) + 3 domain berbeda + audience tahu backup domain + Twitter sebagai jangkar komunikasi — website kamu tidak bisa dimatikan secara efektif. Diblokir di satu domain? Langsung aktif di domain kedua dalam detik. Server di-takedown? Pindah hosting dalam 1 jam, domain masih hidup.
